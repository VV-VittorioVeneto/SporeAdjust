# Local mod dependencies

Place the following Minecraft 1.21.1 NeoForge mod JARs in this directory before building. Versions are defined in `gradle.properties`.

- Spore 2.2.0j
- Iron's Spellbooks 3.15.6
- Iron's Lib 1.0.2
- Player Animator 2.0.4
- GeckoLib 4.8.4
- Curios 9.5.1
- Overworld Mirror 1.8.0.25
- U Team Core 5.6.2.384
- Jade 15.10.5

Download these dependencies from their authors' official distribution pages. Third-party JARs are excluded from Git.
